# 2026-06-26

## 大规模方块3D模型创建 + 光影PBR优化（对标零雾ZeroPBR）

### 新增方块3D模型（8个）

**雕纹书架 (chiseled_bookshelf)**
- 2根竖柱 + 3层横隔板 = 6个书槽
- 正面框架元素突起产生凹陷感

**标靶 (target)**
- 3层同心圆环，从大到小叠高 (0.25/0.5/0.75px)
- 每层环有侧面边缘 UV，光影产生自然层次

**投掷器/发射器 (dispenser/dropper)**
- 前面板外框（上下左右4条框架）+ 内部开口
- 框架元素厚度1px，开口区域凹入

**蜂巢/蜂箱 (bee_nest/beehive)**
- 正面4个孔洞元素（模拟六边形蜂巢）
- 空箱和满蜜状态各有独立模型
- 孔洞使用 bee_nest_inside 深色纹理

### 光影PBR优化
- `NORMAL_MAP_STRENGTH`: 50 → 80（法线效果更明显）
- 新增 `POM_SHADOW_DEPTH 1.00`（POM阴影更深）
